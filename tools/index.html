TOOL 01Ver.1.0

Icon Maker

動画編集や配信活動で使うアイコン素材を、ブラウザ上で制作できるアイコン作成ツールです。

2人分のアイコンを同時に制作でき、それぞれの画像を確認しながら調整できます。設定を引き継いで制作できるため、複数のアイコンを作る際も、一から設定し直す手間を減らせます。

こんなときにおすすめコラボ相手とお揃いのアイコンを用意したいとき／シリーズ動画などで統一感のあるアイコンを複数制作したいとき
🔒 画像はブラウザ内で処理　｜　画像のAI解析・AI学習への利用なし

TOOL 02Ver.1.0

Character Size Maker

複数人のキャラクター画像を並べて、サイズ感を調整・統一できるツールです。

キャラクターごとの身長差や見た目のバランスを確認しながら、複数人のサイズ感を揃えられます。コラボ配信や動画編集で、並べたときの大きさを自然に整えたい場合に便利です。

こんなときにおすすめ複数人の立ち絵を1つの画面に並べたいとき／身長差を活かしながら、全体の見た目を自然に整えたいとき
🔒 画像はブラウザ内で処理　｜　画像のAI解析・AI学習への利用なし
COMING SOON ↗
TOOL 03Ver.1.0

Commission Manager

クリエイター向けの依頼・案件管理をまとめて行える管理ツールです。

制作依頼の進行状況やスケジュールを整理し、見積書・請求書の自動作成、収支の記録など、日々の制作活動に関わる管理をサポートします。

こんなときにおすすめ複数の制作依頼の進捗を整理したいとき／事務作業の負担や時間を短縮したいとき
📋 依頼・案件管理　｜　見積書・請求書　｜　スケジュール管理
COMING SOON ↗
TOOL 04Ver.1.0

Twitch Analytics Manager

Twitchの配信実績を記録・整理し、今後の配信方針やゲーム選びに役立てる分析ツールです。

専用Chrome拡張機能で取得した配信データをまとめて取り込み、平均同接・最高同接・フォロワー増加・ユニークチャット参加者数などを週間・月間、カテゴリー別に確認できます。配信履歴の編集やバックアップにも対応しています。

こんなときにおすすめ配信データを手軽に整理したいとき／数字を比較して今後の配信内容やゲーム選びに活かしたいとき
📊 週間・月間分析　｜　カテゴリー別統計　｜　配信履歴管理
