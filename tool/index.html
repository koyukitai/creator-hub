TOOL 01Ver.1.0

Icon Maker

動画編集や配信活動で使うアイコン素材を、ブラウザ上で制作できるアイコン作成ツールです。

2人分のアイコンを同時に制作でき、それぞれの画像を確認しながら調整できます。設定を引き継いで制作できるため、複数のアイコンを作る際も、一から設定し直す手間を減らせます。

こんなときにおすすめコラボ相手とお揃いのアイコンを用意したいとき／シリーズ動画などで統一感のあるアイコンを複数制作したいとき
🔒 画像はブラウザ内で処理　｜　画像のAI解析・AI学習への利用なし
ツールを開く ↗
TOOL 02Ver.1.0

Character Size Maker

複数人のキャラクター画像を並べて、サイズ感を調整・統一できるツールです。

キャラクターごとの身長差や見た目のバランスを確認しながら、複数人のサイズ感を揃えられます。コラボ配信や動画編集で、並べたときの大きさを自然に整えたい場合に便利です。

こんなときにおすすめ複数人の立ち絵を1つの画面に並べたいとき／身長差を活かしながら、全体の見た目を自然に整えたいとき
🔒 画像はブラウザ内で処理　｜　画像のAI解析・AI学習への利用なし
